Hybrid Data & Event Architecture: Solving Apache Hive Latency with Flowable 3.17 + PostgreSQL + Kafka + Azure Blob
1. Azure Blob Storage (Native)
Flowable Content Engine
Uses out-of-the-box AzureBlobStorageContentStorage (flowable.content.storage.type=azure-blob). Binary scans stream straight to Azure container tax-dms-lux without bloating PostgreSQL.
2. PostgreSQL (Hot OLTP Store)
Sub-20ms UI & Task Queries
Holds Flowable runtime tables (ACT_RU_*), content pointers (FLW_CO_CONTENT_OBJECT), and the flw_tax_dossier CQRS read/write projection so users never wait on Hive MapReduce/Tez queries.
3. Flowable Event Registry + Kafka
Zero-Code Event Outbox
Flowable Enterprise 3.17 natively includes the Event Registry Engine with Kafka Inbound/Outbound channels. BPMN Send Event Tasks emit tax.golden.sync messages on state transitions.
4. Apache Hive (Golden Source)
Enterprise Master Catalog
Kafka Connect / Spark Streaming writes micro-batches into partitioned Hive table bank_golden_dms.tax_documents over ADLS Gen2 / Azure Blob and sends an ack event back to Flowable.
